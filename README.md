# LinkToClip

تطبيق أندرويد لتنزيل الوسائط العامة من روابط مباشرة. واجهة عربية بالكامل (RTL)، وما تختارش المنصة بنفسك — الصق الرابط والتطبيق يكتشف المصدر ويعرض معاينة حقيقية بالصيغ المتاحة قبل ما تقرر تنزّل.

> 💻 **تستخدم ويندوز؟** فيه نسخة كمان لنظام Windows: [حمّلها من هنا](https://github.com/Mahmoudamier/LinkToClip_Windows/releases/tag/v1.0.3)

## تحميل التطبيق (للمستخدمين)

[📥 نزّل آخر إصدار APK من هنا](https://github.com/Mahmoudamier/LinkToClip/releases/latest/download/LinkToClip.apk)

أو افتح صفحة [Releases](https://github.com/Mahmoudamier/LinkToClip/releases) واختار أحدث إصدار.

### طريقة التثبيت
1. نزّل ملف `LinkToClip.apk` على موبايلك.
2. افتح الملف — هيطلب منك تفعيل **«السماح بتثبيت تطبيقات من مصادر غير معروفة»** (خيار عادي لتثبيت APK خارج متجر Google Play).
3. اضغط **تثبيت** وافتح التطبيق.

> التطبيق بيشتغل على **أندرويد 8.0 (API 26) فأعلى**.

## المميزات

- **حقل رابط واحد** واكتشاف تلقائي للمنصة مع أيقونة وشارة عربية.
- **معاينة حقيقية**: الصورة، العنوان، المؤلف، المنصة، المدة، والصيغ المتاحة مع التقدير المتاح للحجم.
- **اختيار الجودة**: تبويبات منفصلة للفيديو والصوت، وتقدير للحجم قبل التنزيل.
- **قوائم تشغيل**: تنزيل قائمة يوتيوب أو SoundCloud Set كاملة، مع اختيار فيديو أو صوت للقائمة كلها.
- **تنزيل في الخلفية**: بيكمل بعد الخروج من التطبيق عبر إشعار دائم، مع حد أقصى 3 ملفات في نفس الوقت والباقي في طابور.
- **التحكم الكامل**: إيقاف مؤقت / استئناف / إلغاء / إعادة محاولة / فتح / مشاركة / إعادة تسمية / حذف.
- **محاولات ذكية**: إعادة المحاولة تلقائياً لأخطاء الشبكة المؤقتة بدل الفشل الفوري.
- **حفظ آمن**: لو مخزن أندرويد رفض الحفظ، الملف بيتحفظ داخل مساحة التطبيق بدل ما يضيع.
- **الثيمات**: فاتح / داكن / حسب النظام — واجهة متجاوبة للموبايل والتابلت.
- **اللغة**: عربية إجبارية جوه التطبيق بخط عربي واضح، RTL كامل.

## حدود مهمة

- التطبيق **بيحمّل محتوى عام فقط**. مفيش تجاوز لـ DRM أو تسجيل دخول أو كaptcha أو حظر جغرافي أو قيود المنصات.
- المحتوى الخاص، المحذوف، المقيد بالعمر أو بالمنطقة هيظهر رسالة خطأ واضحة.
- توفر الصيغ وجودتها بيعتمد على اللي المنصة نفسها بتنشره — التطبيق مش بيخترع روابط أو جودات.
- غالبية المنصات بتمنع إعادة توزيع المحتوى؛ استخدم التطبيق بشكل قانوني وبس للمحتوى اللي مالك حق تحميله.

## البناء من المصدر (للمطورين)

```bash
git clone https://github.com/Mahmoudamier/LinkToClip.git
cd LinkToClip
./gradlew assembleDebug
```

> الـ `local.properties` ومفتاح التوقيع (`release/*.jks`) مش موجودين في الريبو — لازم توفرهم محلياً لو عايز تبني نسخة موقّعة.

الكود متاح للاستخدام الشخصي والتعلم. لا تشمل التطبيق في منتج تجاري بدون مراجعة شروط المنصات والتراخيص دي.
